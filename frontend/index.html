    WAPE: error absoluto total sobre ingresos reales, en 26 semanas de backtesting (siempre pronosticando con datos del pasado). Se elige el de menor error diario, y solo si le gana a la media por 3 % o más. HC es el dataset de control: es aleatorio y el sistema no le encuentra patrones.

    ¿Cuándo avisar? Reglas de alerta evaluadas

    Precisión: de las veces que avisó, cuántas efectivamente se saturó. Recall: de las semanas que se saturaron, cuántas anticipó. La regla de la consigna (esperada > 90 %) casi no da falsas alarmas pero se pierde dos de cada tres saturaciones. Por eso se suma la alerta preventiva con probabilidad ≥ 30 %.
